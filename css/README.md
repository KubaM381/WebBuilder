# CSS structure

- styles.css — allgemeines Builder-Design
- toolbar.css — obere Leiste
- sidebar.css — linke Seitenleiste
- inspector.css — rechter Inspector
- canvas.css — Arbeitsfläche
- responsive.css — Handy/Tablet

Diese Dateien dienen zunächst als Struktur. Bestehendes CSS wird nicht automatisch verschoben oder verändert.
